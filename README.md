# Vending Machine FSM

Designed and simulated a Vending Machine Finite State Machine (FSM) using Verilog HDL in Vivado.

## What it does

This smart vending machine accepts ₹5 and ₹10 coins and dispenses a bottle worth ₹15, returning the correct change if extra coins are inserted.

## Journey

State diagram → Verilog code → simulation waveform, ending with the bottle dispense signal appearing on screen.

## What it taught

How Finite State Machines (FSM) control real-time logic in digital circuits — a key step toward a VLSI front-end design journey.
